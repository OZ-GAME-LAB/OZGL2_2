## 적용 결과

개발자용 조작 패널 대신 최소 HUD와 클릭해서 여는 팝업을 구성했다. 기존 기능 테스트 씬은 유지하고 개선된 화면은 `Assets/Scenes/UI/PlayerUI.unity`에 모았다.

| 화면 | 변경 |
| --- | --- |
| 기본 HUD | 골드, 분기/웨이브, 생존 수, 현재 단계, 건설/웨이브 시작만 노출 |
| 건설 카탈로그 | 2×2 카드, 아이콘·이름·짧은 역할·가격만 표시. 4개 초과 시 페이지 이동 |
| 건물 정보 | 선택할 때만 표시. 존재하는 건설/강화/해체 항목만 노출하며 항목 수에 따라 창 높이 조절 |
| 유닛 정보 | 이름·역할·체력 우선. 전투 수치와 설명은 ‘자세히’ 안으로 이동 |
| 승리 보상 | 작은 3장 선택창. 선택한 유물의 효과만 아래에 표시하고 ‘획득하기’로 확정 |
| 최종 결과 표시 | 승리/패배, 보상, 다시 도전으로 단순화. 실제 최종 승패 이벤트 연결은 별도 |

선택형 팝업은 하나만 열리며 닫기 버튼, 바깥 클릭, Esc 닫기를 제공한다. 건설은 기존 Core 계약으로 제한하고, 필수 보상/결과 창 뒤에서 선택형 팝업을 열 수 없게 했다. 필수 보상은 Esc로 자동 포기하지 않는다.

## 확인 방법

1. 현재 작업 씬을 보존한 상태에서 `Assets/Scenes/UI/PlayerUI.unity`를 직접 연다. 이번 작업은 사용자의 열린 Unity 씬을 전환하거나 저장하지 않았다.
2. Play에서 `건설` 또는 건설 공간의 `+`를 누른다.
3. 카드를 누르면 건물 정보가 열리고 `자세히`/`접기`로 설명을 펼친다.
4. 전사를 누르면 실제 UI 프리뷰 유닛의 체력과 전투 정보를 조회한다.
5. Game 뷰에 포커스를 둔 뒤 Esc와 바깥 클릭도 직접 확인한다.

이 씬은 **UI 레이아웃·연동 프리뷰**다. 배경은 전장 배치를 보여주는 임시 도식이며 팀의 실제 맵이 아니다. 실제 적 AI/건물 생산이 없는 기존 `MvpRuntimeHudSample`의 테스트 전투를 사용한다. 강제 승패·골드 증감 테스트 버튼은 `DeveloperOnly` 아래에 숨겼다. 따라서 이 씬을 완성된 전투 빌드로 간주하면 안 된다.

## 아직 연결되지 않은 기능

- 실제 건설·강화·해체 처리 주체: 프리뷰는 거래를 가장하거나 골드를 차감하지 않는다. 기존 전사 예시 가격 30골드만 표시하고 실행은 비활성화했다. 다른 가격은 `가격 미정`이다.
- 실제 전투의 스폰/디스폰 등록: 현재 생존 수는 프리뷰 유닛만 집계한다.
- Core의 최종 승리/패배 및 최종 정산 결과를 `ShowRunResult`에 전달하는 연결. 결과 캡처는 표시 API를 명시적으로 호출한 검증이며 자동 최종 클리어를 의미하지 않는다.
- 상점, 영구 성장 등 아직 없던 기능은 새로 구현하지 않았다.

개발용 이름이 노출되던 9개 테스트 유물에는 UI 전용 임시 표시명을 설정했다. 예: `artifact_003` → `전리품 주머니`. 실제 ID, 후보 추첨, 수치, 설명, 효과 적용은 팀원 원본을 유지한다. 임시 이름은 기획 확정 후 프리팹의 `_displayNames`에서 바꿀 수 있다. 원본 004/008의 설명·설정 불일치는 [기존 연동 기록](VictoryRewardIntegration20260914.md)을 따르며 이번 UI 작업에서 수정하지 않았다.
