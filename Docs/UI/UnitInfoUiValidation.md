위 수치는 Unity Test Runner 테스트 수가 아니라 **자체 Editor 메뉴의 assertion 수**다.
Editor 검사는 공개 API와 버튼 이벤트를 호출하며, 필요한 생명주기 콜백을 reflection으로 재현한다.
현재 Editor의 기존 Reload Domain 비활성 설정을 유지한 채 Play를 확인했다. 해당 설정을 변경하지 않았다.

## 자체 검사 주요 항목

- 필수 문자열, 음수/0 최대 체력, NaN/Infinity 거부. null 스냅샷/잘못된 체력 갱신의 부분 적용 방지.
- 이름/소속/역할, 아이콘 및 설명 대체 표시, 미제공 전투/특성 영역 숨김과 이전 내용 정리.
- 현재/최대 체력 변화, 동일 값 반복, 체력 0, 최대 초과 값 표시와 게이지 제한.
- 다른 인스턴스 및 같은 병종의 다른 생성 ID를 구분. 오래된 체력/제거 알림 차단.
- 닫기 이벤트 1회와 해당 ID 전달, 중복 닫기/제거 무시, 외부 Hide 시 닫기 이벤트 미발행.
- enable/disable 반복 구독, 비활성 상태 체력 갱신 유지.
- 긴 내용이 뷰포트보다 큰지 검사. 체력 갱신/동일 유닛 새 스냅샷 시 스크롤 유지, 새 선택 시 위로 초기화.

## 실제 Play 확인

1. 시작 시 선택 안내 표시, HUD 100골드 / 1/3 / 유닛 UI 테스트 표시.
2. 전사 선택 → 100/100. 체력 감소 → 75 → 25 → 0, 게이지와 `체력 소진` 문구 일치. 체력 0에서도 선택 유지.
3. 체력 증가 → 25/100, 체력 소진 문구 해제.
4. 궁사 선택 → 60/60, 후열 역할과 전투 정보 표시, 전사의 특성 설명은 남지 않음.
5. 이전 유닛 알림 → 현재 궁사와 60/60 유지, 이전 알림 무시 상태 표시.
6. 경비병 선택 → 적군·비정규군 / 탱커 / 150/150. 제거 알림 → 빈 선택 안내와 정리 상태 표시.
7. 긴 설명 선택 → 휠을 위아래로 스크롤하여 표시 위치 변화와 뷰포트 클리핑 확인. 체력 80→55 갱신 후 읽던 위치 유지.
8. 닫기 → 빈 선택 안내 및 외부 선택 해제 연결용 알림. 전사 재선택 → 정보 정상 재표시.
9. Play 종료 확인. 런타임 변경을 씬에 저장하지 않음. 실제 유닛/저장/재화 변경 없음.

스크롤 샘플은 같은 문장을 반복하므로 큰 휠 입력에서는 처음/끝 화면이 비슷해 보인다.
작은 역방향 휠 입력으로 중간 줄 클리핑 변화를 관찰한 뒤 체력 갱신 시 같은 위치가 유지됨을 확인했다.
드래그 스크롤의 동작은 별도 합격 판정하지 않는다.
