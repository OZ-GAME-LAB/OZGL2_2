### 참고 / 후속 작업

- 팀원 원본 로직·에셋은 수정하지 않고, 필요한 원본 파일과 신규 UI만 추가했습니다.
- 현재는 건설 UI 통합 범위입니다. 실제 전투 전체 흐름·업그레이드·공간 해금·최종 승패/정산 UI는 담당 API 연결 후 진행합니다.
- 건물 이름/그림은 팀 테스트 데이터를 유지했습니다. 최종 디자인/밸런스 완료는 아닙니다.
- 현재 로컬 작업이며 커밋/푸시/PR/머지는 하지 않았습니다. 추후 PR 대상은 `dev`입니다.

## 등록 방법

GitHub 저장소의 Issues → New issue에서 위 제목과 본문을 각각 붙여 넣는다. Assignees는 본인으로 지정하고 실제 팀에서 쓰는 라벨이 있으면 선택한 뒤 Create를 누른다. 이 파일은 초안이며 이슈를 자동 등록한 것은 아니다.
