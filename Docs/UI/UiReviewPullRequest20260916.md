## 로컬 후보 생성 도구

`Tools/UI/Prepare-UiReview.ps1`는 실제 Git index 대신 별도 임시 index로 최신 dev와 UI 변경을 합친다. 실제 작업 브랜치/파일/스테이징은 변경하지 않는다. Git 객체 저장소에는 검토용 blob/tree만 추가하며 커밋/브랜치/원격 PR은 만들지 않는다.

출력 위치: 프로젝트의 `Logs/UiReview-*` (Git 제외).

- `working-backup.csv`, `WorkingBackup/`: 수정/미추적 파일 백업 및 기존 삭제 경로 기록
- `ui-changes.csv`: 포함 파일과 분류
- `ui-only.patch`: 지정 dev에 적용할 UI 전용 패치
- `candidate-project.zip`: 지정 dev + UI만 포함한 검증 복사본
- `summary.xml`: 원본 상태 보존과 후보 tree 기록
- `whitespace-check.xml`: Unity 자동 생성 YAML의 빈 값 공백/Markdown 줄바꿈 진단 기록. C#/PowerShell은 별도 엄격 검사.

패치를 현재 더러운 작업 폴더에 중복 적용하지 않는다. 실제 제출은 변경 보존 상태를 확인하고 최신 dev 기반 정리 브랜치를 준비한 다음, 위 묶음을 검토·커밋·푸시하는 별도 단계다.
