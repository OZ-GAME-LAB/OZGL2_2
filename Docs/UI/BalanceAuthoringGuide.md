# 밸런스 편집기 사용법

Unity 메뉴: **Game → Balance → 밸런스 편집기**

그린라이트의 작업용 복사본 → 테스트 → 명시적 원본 반영 방식을 사용합니다. 창을 열기만 해서는 에셋·씬을 수정하지 않습니다. 팀원 런타임 스크립트는 변경하지 않습니다.

## 순서

빠른 적용: 수치 수정 후 상단 **선택 항목 적용 — 실제 게임 데이터에 저장** → 변경 내역 확인 → **원본 반영**. 적용 완료 창이 표시되면 해당 원본 데이터를 사용하는 게임을 다시 실행합니다. 연결 설정에서 바꾼 스킬 등은 해당 설정 아래의 **이 항목 적용**을 별도로 누릅니다. 복사본 저장과 실제 적용은 다르며 플레이 중 즉시 반영은 지원하지 않습니다.

1. Unity 플레이를 정지하고 현재 작업을 저장합니다.
2. `프로젝트 밸런스 데이터 불러오기`를 누릅니다. **씬 선택은 필요 없습니다.** 기존 작업 공간은 덮어쓰지 않습니다.
3. 분류(유닛/건물/웨이브/재화/아티팩트/상점)에서 데이터를 선택해 수치를 수정합니다.
4. `복사본 저장` → `검증`으로 수정값을 확인합니다.
5. 확정된 데이터에서 `이 항목의 확정값 확인 → 실제 데이터에 반영`을 눌러 변경 전후 값을 확인합니다. 팀원과 합의한 경우에만 최종 확인합니다.
6. 실제 데이터 반영 후 해당 유닛·건물 등을 사용하는 게임에서 변경값을 테스트합니다. 이미 생성된 유닛은 재시작이 필요할 수 있습니다.

`선택 기능: 별도 플레이 테스트`는 필요할 때만 펼칩니다. 이 기능은 선택한 씬을 포함한 **별도의 작업 공간**을 원본 데이터로 만듭니다. 기존 작업 공간의 수정값을 자동 이전하지 않으며, 데이터 편집만 할 때는 사용하지 않아도 됩니다.

## 조정 범위

| 분류 | 조정 가능 |
| --- | --- |
| 유닛 | 기존 능력치 항목의 값, 기본 공격·액티브 스킬의 사거리/시간/대상 수/범위/투사체 속도 등 |
| 건물 | 건설·업그레이드 비용, 필요 코어 레벨, 자원 생산량, 웨이브당 생산 수, 최대 생존 수 |
| 웨이브 | 병종별 등장 상대 가중치 |
| 재화 | 분기·웨이브 보상 수량, 테스트 씬의 시작 재화 |
| 아티팩트 | 최대 중첩 수, 등록된 강화 효과 수치, 후보 수, 등급별 등장 가중치 |
| 상점 | 슬롯 수, 등급 가중치, 구매가 범위, 판매가 |

ID·병종·등급·참조·목록 크기 등 구조는 편집 대상이 아닙니다. 능력치나 건물 종류를 추가하는 도구가 아니며, 팀원이 데이터로 노출하지 않은 하드코딩 값도 바꾸지 않습니다. 현재 `WaveController`의 적 총 생성 수 10은 변경할 수 없습니다. 패시브 스킬의 모든 조건·개별 효과, 영구 성장 전체 수치는 이번 범위에 포함되지 않습니다.

## 저장과 원본 보호

- 새 작업 공간: `Assets/BalanceWorkspace/Editor/Session_.../`. 기본 모드는 팀 ScriptableObject 데이터만 복사하며 씬·프리팹은 복사하지 않습니다.
- 선택 기능으로 테스트 작업 공간을 만드는 경우에만 씬과 의존 프리팹도 복사합니다. 복사 대상끼리 GUID 참조를 연결하고 스크립트·텍스처·폰트·렌더 설정 원본은 수정하지 않습니다.
- 원본으로 확정하는 것은 선택한 ScriptableObject의 허용된 수치 필드뿐입니다. 테스트 씬·프리팹·참조는 원본으로 덮어쓰지 않습니다.
- 복사 이후 원본 파일 또는 미저장 원본이 바뀌면 확정을 중단합니다. 최신 원본에서 새 작업 공간을 만들고 필요한 수치만 다시 입력하세요.
- 외부 Inspector로 복사본의 ID·참조·목록 구조를 바꾸면 원본 반영을 거부합니다.
- 원본 반영 전 백업은 `Library/BalanceBackups/`에 저장합니다. Library는 삭제될 수 있는 로컬 백업이므로 영구 보관은 Git 커밋으로 하세요. 일반 수치 편집 및 원본 반영은 Undo를 지원합니다.
- 테스트 시작 재화는 테스트 씬에만 저장되며 별도로 Ctrl+S가 필요합니다. 원본 반영 버튼에 포함되지 않습니다.
- 테스트 씬의 SaveManager는 Start 이전에 `Library/BalanceSaves/Session_...`로 연결합니다. 원래 플레이어 저장 파일을 사용하지 않습니다. 새 저장 시스템이 Awake에서 직접 저장하거나 SaveManager를 우회하면 별도 검토가 필요합니다.
- Scene Reload를 끈 상태에서는 저장 격리를 보장할 수 없어 테스트 씬 Play 진입을 중단합니다. 프로젝트 설정은 자동 변경하지 않습니다.
- 현재 조정은 **플레이 정지 후 편집 → 재시작 적용**입니다. 이미 생성된 유닛의 실시간 변경은 지원하지 않습니다.

## 팀 공유 / PR

- 도구 코드와 `.meta`, 이 안내서를 공유합니다.
- 실험용 Session 폴더는 기본적으로 PR에 포함하지 않는 것을 권장합니다. 공유가 필요하면 해당 세션 폴더와 `.meta`를 모두 묶습니다.
- 실제 밸런스 변경은 원본 반영 후 GitHub Desktop diff에서 수치 변경만 있는지 확인하고 별도 커밋/PR로 올립니다. 대상 브랜치는 `dev`입니다.
- 도구 자체의 검증 통과는 실제 난이도·전투 AI·전체 게임 루프가 완성되었다는 뜻이 아닙니다.

## 자동 검증

### 편집기 편의 기능 (2026-10-06)

- 그린라이트 편집기처럼 **왼쪽 분류 → 조정할 항목 → 오른쪽 수치 편집** 순서로 사용합니다. 각 분류에 조정 시 고려할 설명을 표시합니다.
- 작업값과 원본값을 나란히 표시합니다. 파일 경로는 `고급 정보`를 켜면 표시됩니다.
- 건물·유닛의 `함께 조정할 연결 설정`을 펼치면 화면 이동 없이 관련 복사본 수치를 수정합니다. 공유된 스킬은 다른 연결 유닛에도 영향을 줄 수 있습니다.
- 저장은 복사본 저장입니다. 원본 반영은 각 데이터의 `이 항목의 확정값 확인 → 실제 데이터에 반영`에서 변경 내용을 확인한 후 실행합니다. 일괄 반영이나 실제 저장 데이터 초기화 기능은 추가하지 않았습니다.

- 기본 작업 공간은 씬 없이 프로젝트의 유닛·건물·보상·아티팩트 등을 불러옵니다. 선택 테스트 기능은 씬을 명시적으로 선택해야 하며 기본 씬을 자동 지정하지 않습니다.
- 유닛은 실제 UnitData의 아군 티어 / 적군 팩션으로 필터링합니다. 이름·Type·경로 검색을 지원합니다. Type이나 소속 자체는 변경하지 않습니다.
- 유닛의 `연결 데이터` 버튼으로 공격·스킬·패시브 복사본을 찾아갑니다. 패시브는 주기와 조건 검사 간격만 수정 가능하며 조건·효과 구조는 보호합니다.
- 새 패시브 편집 기능은 **새 작업용 복사본**에서 사용하세요. 이전 세션은 기존 편집 범위를 유지합니다.
- 권장 순서: 건설/업그레이드 비용 → 웨이브 보상 → 유닛/스킬 → 유물 효과 → 분기별 플레이 비교. 기본 공격 DPS를 전체 전투력으로 간주하지 않습니다.
- 엑셀 제안 수치나 적 성장치는 자동 적용하지 않습니다. 실제 스킬 효과·생존력·누적 골드와 유물 조합은 플레이 테스트로 판단합니다.

### 실행 방법

`Game.UI.Editor.BalanceAuthoringValidation.RunBatch`는 `UnityUIValidation` 경로의 격리 프로젝트에서만 실행됩니다. 팀 프로젝트에서 자동으로 원본 반영 테스트를 실행하지 못하도록 제한했습니다. 검증 결과는 `Logs/BalanceAuthoring/`에 기록됩니다.

### 2026-09-30 검증 결과

- Unity 6000.3.23f1 컴파일 및 보호 검사 25개 통과: 231개 복사본 생성, 원본 파일 보존, 참조 격리, 연결 검사, Undo/Redo, 원본 변경 차단, ID 변경 차단, 명시적 수치 반영/백업.
- Play Mode 검사 6개 통과: 시작 골드 500, 테스트 SaveManager 저장 경로 분리, 실제 카탈로그 선택/건설, 비용 17 차감 후 483, 생성된 아군 체력 12,345. 이 수치는 격리 검증용이며 팀 원본에는 반영하지 않았습니다.
- `BalanceAuthoringPlayValidation.RunBatch`는 앞선 검사로 만든 격리 작업 공간에서 실행합니다. 실제 팀 프로젝트 실행을 차단합니다.
- 기존 `PreviewWarrior.asset`, `RuntimeSelectionAlly.asset`, `RuntimeSelectionEnemy.asset`의 능력치 enum 값 1이 최신 팀 정의와 맞지 않습니다. 셋 모두 현재 테스트 씬에 미연결인 UI 미리보기 데이터입니다. 검증에서 보고하며 자동 수정하지 않습니다.
- 전체 자연 전투 승리/보상 루프와 출시 빌드는 이번 도구 검증 범위가 아닙니다. 스킬별 실제 효과와 모든 상점 조합도 개별 플레이 검증이 필요합니다.
