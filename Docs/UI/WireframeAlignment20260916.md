## 담당 시스템 연결 계약

### 유물 목록

`ArtifactInventoryPanel`은 `ArtifactManager.Instances`, `StackChanged`, `Cleared`만 읽는다. UI가 유물을 생성하거나 효과를 적용하지 않는다. 실제 정의에 아이콘이 없으면 임시 도형을 사용한다. 기존 UI용 표시 이름만 재사용하고 팀 데이터 에셋은 바꾸지 않는다.

### 원정 결산

`RunSettlementPanel.Show(RunSettlementViewData)`에 정산 소유자가 확정한 스냅샷을 전달한다.

- 토템 요약, 진행 기록, 획득 유물 요약, 종합 점수, 획득 혈석, 게이지 현재/목표.
- `null`은 연결 대기, 숫자 `0`은 실제 0 보상으로 구분한다.
- 음수와 유효하지 않은 게이지는 거부한다.
- 화면 표시는 재화 지급이나 저장을 수행하지 않는다. 정산 소유자가 별도로 일회 지급을 보장해야 한다.
- 현재 `GameUIController.ShowRunResult`는 `ShowPending`으로 연결되어 있다. 골드 보상을 혈석으로 임의 변환하지 않는다.
- `MainMenuRequested`를 담당자가 구독하면 메인 이동 버튼이 활성화된다. 요청 중 재클릭을 막으며 실패 시 소유자가 `ResetMainMenuRequest()`로 해제한다. 실제 씬 이동은 소유자의 책임이다.

현재 연결 대기 표시는 개발 중인 상태를 알리기 위한 것이며, 최종 플레이어 화면에서는 실제 정산 데이터가 제공되어야 한다.
