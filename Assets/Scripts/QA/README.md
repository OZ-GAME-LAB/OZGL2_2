# 전투 밸런스 QA

`Assets/Scenes/Test/QA.unity`를 열고 Play를 누릅니다. 런·건설·경제 시스템 없이 기존 유닛 프리팹과 전투 시스템을 실행합니다.

## 사용 흐름

1. 왼쪽에서 진영, 등록된 유닛, 수량(1~5)을 선택하고 **유닛 생성**을 누릅니다. 한 번에 최대 5명이며 여러 번 추가할 수 있습니다. 미등록 종류는 ‘생성 불가’로 표시합니다.
2. 왼쪽 병력 목록이나 전장의 유닛을 선택합니다. 준비 상태에서 전장 빈 위치를 클릭하면 선택 유닛의 시작 위치가 바뀝니다.
3. 양쪽 병력이 집결하면 **전투 시작**이 활성화됩니다. 전투 중 구성·배치는 잠기며 선택·정보 확인은 가능합니다.
4. **일시정지 / 재개**는 유닛·투사체·지속 효과·전투 시간을 함께 멈추고 재개합니다. **전투 중단**은 부분 결과를 고정합니다.
5. **전투 초기화**는 병력·배치를 유지하고 유닛을 새로 생성해 HP·상태·현재 통계를 초기화합니다. 종료 후 **같은 조건 재전투**는 초기화 후 자동 시작합니다.
6. 준비 상태의 **구성 비우기**는 병력과 현재 통계를 모두 제거합니다. 결과를 기록하려면 초기화 전에 확인해야 합니다.

## 측정 기준

- 팀 결과·시간·생존/사망, 개별 처치·생존 시간, 잔여 HP/보호막을 표시합니다. 사망한 유닛은 병력 목록에서 계속 선택할 수 있습니다.
- 받은 HP 피해와 보호막 흡수를 분리하며 과잉 피해는 실제 HP 감소량까지만 집계합니다. 최대 HP·보호막 상한 보정은 피해로 계산하지 않습니다.
- 회복·보호막 부여는 실제 적용량입니다. 유닛별 합계는 받은 회복·받은 보호막을 의미합니다.
- 스킬 성공·실패·중단은 기존 `SkillExecutionEnded` 결과이며 늦게 명중하는 투사체나 DoT의 피해 기여도는 포함하지 않습니다.
- 아티팩트·제단·특성은 현재 적용되지 않습니다. 설정 탭에서 미연결·데이터 검증 사유를 확인할 수 있습니다. 가한 피해/DPS/스킬별 피해 기여도는 미지원입니다.
- 같은 조건 재전투는 구성과 시작 좌표를 재현합니다. 난수 시드 고정 및 완전한 결정론적 재생은 이번 버전의 기능이 아닙니다.
- 초기화는 QA 씬이 소유한 시체·그룹·유닛·투사체·지속 효과와 구독을 정리합니다. 씬을 종료하면 QA가 사용한 `Time.timeScale`을 복원합니다.
- QA 씬 실행 중에는 비포커스 상태에서도 시뮬레이션이 진행되도록 `Application.runInBackground`를 켭니다. 씬 종료 시 진입 전 설정을 복원합니다.
- 전장은 `BattleCamera`의 RenderTexture로 표시합니다. `DisplayCamera`는 Display 1에 배경만 출력하므로 `Target Texture = None`, `Culling Mask = Nothing`을 유지합니다. 이 카메라를 제거하면 Game 뷰의 ‘No cameras rendering’ 안내가 UI 위에 나타날 수 있습니다.

## 검증

QA 씬에서 Play 중 `Tools > QA > Run Scene Verification`을 실행하면 생성·배치·준비 조건·통계 실제 적용량·최대 HP 상한·사망/처치·반복 초기화·실제 전투 종료·재전투·투사체/DoT 일시정지를 검증합니다. 콘솔과 `Temp/QA/verification.txt`에서 결과를 확인합니다. 검증기는 Editor 전용이며 씬/프리팹에 저장되지 않습니다.

별도 에이전트의 실제 씬 검토 결과, 사용성 개선과 후속 밸런스 기능 제안은 [독립 QA 보고서](../../../PersonalDocs/2026-10-03-QA-Combat-Review.md)에 기록했습니다.

`QASceneBuilder`는 최초 씬·프리팹 생성용입니다. 이미 생성된 QA 에셋은 재생성하지 않고 Inspector 및 Prefab Mode에서 수정합니다. 런 저장·불러오기 기능은 없습니다.
